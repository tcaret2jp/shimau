それ以外のダウンロードは、Brave の設定のまま。いつもの使い心地は変わりません。

クラウドや SSD に直接

Google ドライブ・Dropbox・外付け SSD など、Finder やエクスプローラーで見える場所ならどこでも。

ファイルは消えない

SSD を外しているなど保存先が見つからないときは、ダウンロードフォルダに残して通知します。

上書きしない

同じ名前のファイルがあれば「名前 (1).pdf」のように、ブラウザと同じ付け方で保存します。

Mac と Windows で共有

ルールを書き出して、もう一方の PC で読み込めます。保存先は PC ごとに設定できます。

ネットに送らない

ファイルを動かすヘルパーはネット通信をしません。ダウンロードフォルダ内のファイルしか動かしません。

履歴が残る

いつ・どのファイルを・どこへしまったか、直近 200 件をあとから確認できます。

Brave に読み込む

Brave で brave://extensions を開き、「デベロッパーモード」を ON。「パッケージ化されていない拡張機能を読み込む」で extension フォルダを選びます。

はじめての設定

自動で開く画面の案内に沿って、小さなヘルパーアプリを入れます。手順は動画で確認できます。

よくある質問

気になるところ

無料ですか？

はい、無料です。アカウント登録もいりません。

登録していないサイトのダウンロードはどうなりますか？

何もしません。Brave で設定しているフォルダに、いつもどおり保存されます。

なぜヘルパーアプリが必要なのですか？

ブラウザの拡張機能は、ダウンロードフォルダの外にファイルを保存できないためです。ヘルパーは、ダウンロードが終わったファイルを保存先へ移す役目だけを持つ小さなアプリで、Brave が必要なときだけ起動します。

SSD を外していたり、Google ドライブが止まっていたら？

ファイルはダウンロードフォルダに残し、「保存先が見つかりません」と通知でお知らせします。ファイルがなくなることはありません。

インストールのとき、警告が出ました。

Apple や Microsoft に登録していないアプリのため、最初の 1 回だけ確認が出ます。はじめての設定画面に、Mac は動画、Windows は手順で対処のしかたを載せています。

Chrome や Edge でも使えますか？

いまは Brave のみに対応しています。

アンインストールするには？

拡張機能は brave://extensions から削除します。ヘルパーは、ダウンロードしたヘルパーをもう一度開いて「削除する」を選びます。
