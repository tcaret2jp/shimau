    ヘルパーを入れる

    ファイルを Googleドライブや SSD へ移動する小さなアプリです。ネット通信はしません。管理者権限も不要です。

    Mac 用をダウンロードWindows 用をダウンロード shimau-helper-macwindows.zip

    ダウンロードが終わったら、ターミナルを開いて次のコマンドを貼り付けて実行してください。

    ダウンロードが終わったら、PowerShell を開いて次のコマンドを貼り付けて実行してください。

    cd ~/Downloads && unzip -o shimau-helper-mac.zip -d shimau-helper && bash shimau-helper/install.sh try { cd ~\Downloads -ErrorAction Stop; Expand-Archive -Force shimau-helper-windows.zip shimau-helper -ErrorAction Stop; powershell -ExecutionPolicy Bypass -File .\shimau-helper\install.ps1 } catch { Write-Host $_ -ForegroundColor Red }
    ターミナルは Spotlight（⌘ + スペース）で「ターミナル」と入力すると開けます。
    PowerShell はスタートメニューで「PowerShell」と入力すると開けます。
    ヘルパーの接続を待っています… インストールが終わると自動で次へ進みます。
    ヘルパーとつながりました（v0.1.0）
    うまくいかないときは、Brave を一度終了して開き直してください。

    ルールを作る バックアップから読み込む
あとで設定する場合は、このタブを閉じてください。設定画面の「ヘルパー」からいつでも再開できます。

動きの説明（モック用メモ）

  • 拡張機能を入れた直後に、このページが新しいタブで自動的に開く（初回インストール時のみ。更新時は開かない）。
  • OS は自動で判定し、Mac / Windows の手順だけを表示する。
  • 「ダウンロード」は GitHub Releases の最新版 zip を直接ダウンロードする。
  • このページを開いている間は 2 秒ごとにヘルパーへ接続を試し、つながったら自動でステップ 3 へ進む。
  • ヘルパーがすでに入っている（再インストールなど）場合は、ステップ 2 を完了済みにして表示する。
