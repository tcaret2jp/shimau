準備ができました

これからは univ.ac.jp のダウンロードが 大学資料 に自動でしまわれます。

ほかのサイトは、そのページで右上の shimau アイコンを押すと 1 クリックで追加できます
ルールと保存先は「設定」でまとめて編集できます
もう一方の PC では「バックアップ」で書き出したファイルを読み込むだけです

動きの説明（モック用メモ）

  • カードは中央に 1 枚、前後のカードが左右に薄く見えるカルーセル。「次へ」「戻る」・← → キー・トラックパッドの横スワイプで移動。
  • ヘルパー：zip / exe をダブルクリックするだけで、自分自身をインストールする（コマンド不要）。署名していないアプリのため、初回だけ Mac / Windows の確認画面が出る（これを無くすには Apple・Microsoft の有料の開発者署名が必要）。
  • ヘルパーが既に入っていれば、ステップ 1 は飛ばして分かれ道から始まる。
  • バックアップを読み込む：その場でファイルを選んで取り込み、完了カードへ（使い方の説明は飛ばす）。
  • 保存先・ルール：このカード上で実際に作る。「選ぶ」はヘルパーのフォルダ選択ダイアログ、マウント中の場所は自動で候補表示。
  • 保存先・ルールがすでにある場合（2 回目以降に開いたとき）は、分かれ道に「設定を開く」を出す。
