# shimau（しまう）

Brave（Mac / Windows）で、登録したドメインのダウンロードだけを指定フォルダ（Googleドライブ・Dropbox・外付けSSD 含む）へ自動で振り分ける拡張機能＋ヘルパーアプリ。

> **名前の由来**：ダウンロードしたファイルを、あるべき場所に「ちゃんとしまっておくね」→ しまう → **shimau**。姉妹リポジトリ pomoru（ポモる）と同じく、やさしい日本語の動詞から付けた（2026-11-17 決定）。

## 構成
```
extension/        Brave 拡張（Manifest V3、素の JS + CSS）
  background.js   ダウンロード監視 → ルール判定 → 完了後にヘルパーへ移動を依頼
  lib/            ドメイン判定・バックアップ・ストレージ・ヘルパー通信
  popup/ options/ ポップアップ・設定画面
helper/           ネイティブヘルパー（Go）
  install*.go     ダブルクリックで開いたときのインストーラー（自分をコピーして Brave に登録）
  build.sh        Mac 用アプリ（zip）と Windows 用セットアップ（exe）を dist/ に作る
  tools/macapp.py Mac 用アプリを Pi 上で組み立てる（ユニバーサルバイナリ・アイコン・Info.plist）
  sign-mac.sh     Pi で署名できないときに、Mac で Mac 用アプリを署名する
  install/        旧インストールスクリプト（v0.1 のターミナル用。配布物には入れない）
tests/            拡張の単体テスト（node --test）
docs/             要件定義・デザインモック
```

## インストール
### 1. 拡張機能（Mac / Windows 共通）
1. Brave で `brave://extensions` を開き、右上の「デベロッパーモード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」→ このリポジトリの `extension` フォルダを選ぶ
3. 拡張機能 ID が `clnofopcnjnjgknoflaipaohdofeolng` になっていることを確認（manifest の key で固定）
4. 「はじめての設定」タブが自動で開くので、その案内どおりにヘルパーを入れる（設定画面の「ヘルパー」からも開ける）

### 2. ヘルパー
はじめての設定画面の「ダウンロード」から入れる（中身は `helper/build.sh` で作る `helper/dist/` のファイル）。
- Mac：`shimau-helper-mac.zip` を開き、出てきた「shimau ヘルパー」をダブルクリック。初回は「開けません」と出るので、システム設定 → プライバシーとセキュリティ → 「このまま開く」
- Windows：`shimau-helper-setup.exe` をダブルクリック。初回は「PC が保護されました」と出るので、「詳細情報」→「実行」

「インストールしました」と出れば完了。管理者権限は不要。同じ版をもう一度開くと「入れ直す／削除する」を選べる（アンインストールもここから）。
ヘルパーの置き場所：Mac `~/Library/Application Support/shimau/shimau-helper`、Windows `%LOCALAPPDATA%\shimau\shimau-helper.exe`。

### 実機での確認項目
0. ヘルパーのインストール
   - Mac：zip を開いてダブルクリック → 「開けません」→「このまま開く」でパスワードを聞かれるか、文言が画面の見本どおりか → 「インストールしました」が前面に出るか
   - Mac：はじめての設定画面の「設定を開く」で、プライバシーとセキュリティが直接開くか
   - Windows：Brave が exe のダウンロード時に警告を出すか → SmartScreen の「詳細情報」→「実行」→「インストールしました」
   - 入れたあと、Brave を再起動しなくても「はじめての設定」が自動で次へ進むか
   - 同じファイルをもう一度開く →「削除する」で消えるか
1. 未登録サイトでダウンロード → Brave 標準のフォルダに保存される
2. 登録サイトでダウンロード → ローカル／Googleドライブ／Dropbox／SSD に移動され、通知が出る
3. SSD を外した状態でダウンロード → ダウンロードフォルダに残り、通知が出る
4. 同名ファイル → 「名前 (1).拡張子」で保存される
5. Mac でバックアップを書き出し → Windows で読み込み → ルールが反映される
6. 保存先の追加画面で「選ぶ」→ フォルダ選択ダイアログが出る

### 補足・既知の制限
- Brave のダウンロード先を `~/Downloads` 以外にしている場合は、ヘルパーの設定ファイル（Mac：`~/Library/Application Support/shimau/config.json`、Windows：`%APPDATA%\shimau\config.json`）の `extraDownloadDirs` にそのフォルダを追加する。安全のため、ヘルパーはダウンロードフォルダ内のファイルしか動かさない。
- ダウンロード元のページが分からない（referrer がない）ときは、その時点で開いているタブで判定する。裏のタブから始まったダウンロードは、手前のタブのルールで振り分けられることがある。
- Brave の「保存する前に保存先を確認する」が ON だと、振り分け対象でもダイアログが出る。
- ダウンロード中に Brave を終了し、次回起動後に再開して完了したファイルは振り分けない（判定はブラウザを閉じると消えるため）。
- 別ドライブ（Googleドライブ・SSD など）へのコピーの検証はサイズの一致まで。中身の読み直し比較はしない（大きいファイルで時間がかかるため）。

## v0.1.1 の改善（Codex × Claude Code の相互レビュー）
- 大きいファイルを別ドライブへコピーしている途中で、拡張機能のバックグラウンドが止まって処理が切れることがあった → ヘルパーとの接続を保ったまま処理するように変更
- 別ドライブへのコピーは、保存先に隠しの一時ファイル（`.shimau-….part`）として書いてから正式な名前に付け替える。途中で止まっても壊れたファイルが完成品の名前で残らない（1 日以上前の一時ファイルは次回に片付ける）
- コピー中に元ファイルが別のファイルに差し替えられていたら、元を消さない
- 名前の末尾に空白があるファイル（`report.pdf `）を別のファイルと取り違えていたのを修正
- `archive.tar.gz` の連番を `archive (1).tar.gz` に（ブラウザと同じ付け方）
- ポップアップと設定画面が、ほかの画面での変更を古い内容で上書きしないように（保存の直前に最新の内容を読み直す）
- 設定画面：変わった部分・表示中の画面だけを描き直す（ダウンロードのたびに全画面を作り直していた）。ダイアログを開いている間は背面を操作できないように
- ヘルパーへの問い合わせをまとめて、起動回数を減らした（設定画面を開くとき 2 回 → 1 回、保存先の再同期を含む移動 3 回 → 1 回）
- ダウンロードのたびに履歴 200 件まで読み込んでいたのをやめた。ポップアップの初期表示を並列化
- バックアップ：保存先の id が重複したファイルは読み込まない
- Mac のインストール：ホームフォルダのパスに `"` や `\` があっても壊れないように。上書きインストールで起動できなくなる問題を避けるため、別名でコピーしてから置き換える

## 開発
```bash
npm test                                   # 拡張の単体テスト
cd helper && go test ./... && ./build.sh   # ヘルパーのテストとビルド
```
Go は Pi の `~/.local/go`（sudo なしで導入）を使う。
Mac 用アプリの署名（ad-hoc、無料）は Pi の `~/.local/bin/rcodesign`（apple-codesign 0.29.0）で `build.sh` が自動で行う。署名しないと Mac で「壊れているため開けません」になるため、rcodesign がないときは `shimau-helper-mac-unsigned.zip` だけを作る（そのときは Mac で `helper/sign-mac.sh`）。
